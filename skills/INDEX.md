## Add your own

1. Make a folder in `my-business/skills/<name>/` with a `SKILL.md` that starts with a `name` and a `description`, like the files here.
2. Tell the COO "add this skill to [AGENT]". It gets listed in that agent's setup file.
3. Keep your own skills in `my-business/`, so updates to this repo never overwrite them.
