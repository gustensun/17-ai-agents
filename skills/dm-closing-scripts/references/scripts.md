# The scripts

Adapt every message to the person and to the owner's voice before it goes out. Brackets are placeholders: [NAME], [SERVICE] (what the owner sells, for example a funnel build, a website, a coaching program), [THEIR SITE], [PRICE], [TIMELINE]. A line in a code block is one message. Send it, then wait a moment before the next one, like a person typing.

## 1. The comment

When someone posts that they need help with what you do. Tag them so they get notified.

```
Hey [NAME], I just finished a [SERVICE] for a [SIMILAR BUSINESS] and I'm available to help now. Happy to send you my portfolio with more examples if you want to check them out?
```

When they reply:

```
Hey [NAME], happy to send over my portfolio.
```
```
Let me know what kind of [SERVICE] you're looking for, so I can send something similar to what you need. I've got a lot of different ones.
```
```
Here are a few examples to show you what we can do. I can send more once I know a bit more about what you're looking for.
```

Then wait for them to talk.

## 2. Outbound connect

Wait 24 to 48 hours between messages. Stop after follow-up 4.

```
Hey [NAME], is [THEIR SITE] your main site where you sell your offers right now? I [WHAT YOU DO] for [THEIR KIND OF BUSINESS], so I wanted to connect and offer you a free [MAKEOVER OR SAMPLE] if you're interested. No need to send me anything or jump on a call, I can use what you already have.
```

Follow-up 1:
```
By the way, there's no catch. I want to work with more great people, so I'm doing a few projects free of charge if we're a good fit. Not sure if you're interested or need this right now?
```

Follow-up 2:
```
Also, what software do you use for your [PAGES OR PROJECTS]? I'm happy to send you a free template too for any offer you're planning to launch soon. Let me know which one you want and I'll grab it for you.
```

Follow-up 3:
```
I had some time today, so I recorded a quick screen video showing a few things that could help you get more from [THEIR SITE OR OFFER]. Cool if I drop it here?
```

Follow-up 4:
```
Not sure my messages are coming through, but it's all good. You know where to find me if you need [SERVICE]. I've got a few free resources, checklists and templates I'm happy to share any time.
```

## 3. Collect: paid or free

```
Happy to help. I love working with people like you. What's the main offer or project you need help with right now? Is it this one: [LINK]?
```
```
Got it. And you just need [WHAT THEY SAID] on this one, nothing else right now?
```
```
OK, so you want [MIRROR BACK WHAT THEY WANT]. When would you ideally want this done?
```

If it's a paid project:
```
I can definitely help you with all that. I'd have to charge a little for it, but it won't be as much as I usually charge, since I reached out to you first.
```

When they ask how much:
```
Usually I charge [FULL PRICE], and that includes everything from [FIRST STEP] to [LAST STEP], fully done and live within [TIMELINE]. Since it's our first time working together, I can do it for [PRICE] for the whole thing.
```

When they ask about next steps:
```
I've got a few questions in an onboarding form I'd love for you to fill out. Then I'll take care of everything else from there, since we'll have it all in one place.
```

If it's a free project:
```
Sounds good, I can do that for you. Anything I should know about your offer or what you want, besides what's already on your site?
```
```
I'll get to work and keep you updated here. And after this one, do you have any other [PROJECTS] you're thinking about launching soon?
```

If they do:
```
Why don't I do both for the price of one, in the same process? We can use the same style for both, so you save some money too.
```

## 4. Close: invoice and onboarding

```
I'll get you the invoice and the onboarding form in a minute. What company name do you want on the invoice?
```
```
Hey [NAME], excited to work with you on [PROJECT]. Here's the invoice: [INVOICE LINK]. And here's the onboarding form: [FORM LINK]. Let me know if you have any questions.
```

The clarity closer, when they ask "what are the next steps?":
```
I'll send you the invoice, and once that's taken care of, I'll send you an onboarding form that collects everything about [PROJECT], so I have it all in one place and can build it from there.
```
```
That way you can focus on other things while I build, and I don't have to bother you going back and forth.
```

Wait for their reply, then:
```
Once you've filled it out, I'll check that nothing is missing and confirm I have everything. Then it'll be done in [TIMELINE].
```

For bigger projects, offer 50% up front and 50% on delivery if they ask.

## 6. Follow-ups

When they asked for the portfolio or the price and went quiet.

```
Hey [NAME], just checking in to see if you already found someone, or if you're still interested in [OUTCOME]?
```
If they were busy:
```
No problem, I just wanted to plan for your project so we keep the timeline and get it launched for you as soon as possible.
```
If they stop replying:
```
Did you have any other questions I can answer before we get started?
```
If they haven't said when they want it:
```
Our usual turnaround is [TIMELINE]. Does that work for you, or do you need it faster?
```
If price is the issue:
```
Totally understand. Would a payment plan help, with 50% up front and 50% in 30 days?
```
After a few days of silence:
```
No hard feelings if you already found someone, just let me know so I can close this conversation.
```
```
I know you're busy, so I gave you some space. I just finished another project, so I can start on yours now if you want.
```
When they say yes:
```
I'll send over the invoice and we'll get started: [INVOICE LINK]. Let me know when it's taken care of and I'll send the onboarding form.
```
```
Got it, thanks. I went through your form and I have what I need. I'll get to work, and I'll reach out if I need anything.
```

## 7. Questions before closing

These make the buyer feel understood and show you know the work. Ask the ones that matter for this project.

1. What is the offer and who's it for?
2. Do you have other products or services you'd like to offer on the back end?
3. Do you have an existing site for this offer?
4. What software are you using?
5. Do you have any testimonials or case studies we can use?
6. What are your biggest traffic sources right now?
7. Do you want me to write the copy as well?
8. Do you have a follow-up email sequence in place?
9. Do you want me to set up the tech side as well, so it's fully live?
10. Do you have someone on your team to manage and improve it?
11. Would you like me to build everything start to finish, so it's live in [TIMELINE]?

## 8. Your first 10 clients

Three messages. No ask, just give. Find their site from their profile links or a search.

```
Hey [NAME], I checked out your site at [THEIR SITE] and wanted to see if you'd want a free redesign.
```
```
I'm building [SERVICE] for people like you in [NICHE], and I'd be happy to do one for you for free in exchange for a testimonial.
```
```
And only if you love it, of course.
```

Only the first piece is free, as a sample of your work. When they ask for more, give them a custom paid offer at a reduced rate. A few very happy clients are worth more than many half-happy ones. When they say yes:

```
Great, I'll send over my regular client onboarding form, so I have everything I need to make something great for you.
```

## 11. The case study post

Post one version, adapted to the niche. Try all three over one to two weeks.

```
Attention [NICHE]: want a free [SERVICE], done for you, without paying a single dollar?

I'm looking for 2 [CLIENTS WHO FIT THESE CRITERIA] to [BUILD A NEW ONE OR REDESIGN YOURS].

Why? I'm adding a couple more case studies to my portfolio. Instead of asking you to pay, all I ask is a testimonial if you're happy with the results.

Sound fair? Comment "Interested" and I'll pick 2 people.

P.S. You need an existing business with a proven offer.
```
```
Want a free [SERVICE]? I've got something for you. Comment "Interested" below.
```
```
[NICHE], want a free [SERVICE]?

I'll [EVERYTHING YOU'LL DO] for you. The catch: give me a testimonial if you're happy.

Only 2 spots. Comment #CaseStudy if you're interested.
```

Then the seven steps:

1. **Reach out to the people who commented.**
```
Hey [NAME], saw your comment on the post. Do you already have an offer or a site you'd want the free [SERVICE] for? I checked your profile and you look like a great fit for this case study.
```
```
Thanks, checking now. Looks like I can definitely help. Again, it's free for you, since I'm adding a few case studies to my portfolio. All I ask is that if you like it, you give me an honest review or testimonial.
```
2. **Onboard.**
```
I'll send you the onboarding form, and as soon as that's done I'll get to work and have it back to you in a few days. Here you go: [FORM LINK]
```
```
Saw you filled out the form, thanks. Looks like I have everything I need. I'll get to work and keep you updated.
```
3. **Communicate often.**
```
Hey [NAME], it's almost done, so I'll send it over today or tomorrow at the latest.
```
4. **Deliver** with a short screen recording that explains your thinking.
```
Hey [NAME], here's [THE PROJECT] for you to review: [LINK]. I recorded a short video of my thought process too: [VIDEO LINK]. Any questions or edits, just let me know and I'll update it within 24 hours.
```
5. **Ask for the testimonial** once the edits are done and it's live.
```
Hey [NAME], I've made all the updates. For the testimonial, it's simple: a 20 to 60 second video or a few lines of text, an honest review of what it was like working with me, and whether you'd recommend me to others. Thanks in advance.
```
6. **Offer the next project.**
```
Thanks for the testimonial, I really appreciate it. Are there any other [PROJECTS] you'd need, or a new offer you're thinking about launching?
```
7. **Price it as a returning client.**
```
Happy to do that one too, so everything has the same style. I love long-term client relationships, so instead of [FULL PRICE], the usual fee, I can do it for [PRICE], done in [TIMELINE].
```

## 12. The sales call

Some people want a short call because it feels like too much to share in a chat. Keep it to 15 to 30 minutes and follow the same 3C's. If they're a good fit, tell them the price. If they're not, don't invite them to work with you.

The ten questions (adapt them to the project):

1. "I'd love to hear more about your offer and what you're selling, so I understand what makes the most sense."
2. "What's the price of the offer? It changes the approach: a high-ticket offer usually needs an application, a lower one an order form."
3. "Who do you serve? Do you have a typical customer?"
4. "Do you have other offers on the front end or back end? I like to see the full picture."
5. "Where does your traffic come from, organic or paid? We want the front end to be profitable, or at least break even."
6. "Do you already have a site I could look at? Sometimes we build from scratch, sometimes we improve what you have."
7. "What are your conversion rates from start to finish? Just so I know if there's room to improve."
8. "What do your automations and follow-up emails look like? Do you need us to build those too?"
9. "What software do you use?"
10. "This all sounds good. I can help with all of it and have it live within [TIMELINE]. When would you want it done by?"

Bring the portfolio and two or three examples from their space to every call. When they see the kind of thing they want, it gets easier to say yes.
