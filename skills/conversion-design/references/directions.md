# Directions, palettes, type and motion

"Modern, clean, professional" is how a page ends up looking like every other AI page. A named direction gives the build one real idea to organize around. Pick one direction, one palette and one type pairing, then write the Style Block.

## Pick a direction

1. Read the avatar, the offer and the proof bank in the Brain, and look at the photos the owner has.
2. Choose three directions from the menu that fit the avatar (the person, more than the niche).
3. For each one, write: why it fits this avatar, the hero in two sentences, a palette, a type pairing, one motif from the owner's world, and the one risk with how to avoid it.
4. Recommend one. Choose light or dark from where and when the avatar reads the page.
5. The owner approves. Write the Style Block and save it to the Style block in section 10 of `my-business/BRAIN.md`.

## The Style Block

Fill this in, keep it under 250 words, and save it to the Brain. It goes into every design and build request.

```
STYLE BLOCK
- Direction: [name] + the idea in one sentence
- Hero concept: what the first screen looks like
- Colour tokens: --bg, --surface, --ink, --muted, --accent, --accent-ink (hex, 6 max). Where the accent is allowed.
- Type: display font (weight, tracking, line height, clamp size range); text font (size, line height, 65 to 75 characters per line). Where each font loads from.
- Optional accent: one italic serif word per headline, or none
- Layout: grid, max width, edge margins, one section per screen
- Shapes: corner radius scale, border style, shadow (soft blur with offset, never a glow)
- Buttons: one primary style (solid, high contrast), one secondary style (text link), hover and press
- Imagery: photo style, what's allowed, what's banned
- Motif: one shape from the owner's world and where it repeats (4 places max)
- Motion: the hero entrance, the one signature moment, hover rules
- Never: 6 things this brand must never do
Every text pair passes AA: 4.5:1 body, 3:1 large text.
```

## What AI slop looks like, and the fix

| Slop | Fix |
|---|---|
| Purple or blue gradient everywhere | One palette, the accent only on the button and key highlights |
| Rows of equal cards: icon, heading, two lines | Vary the layout per section. Lead with outcomes. Use photos, lists, quotes, comparisons, diagrams |
| A small uppercase label above every heading | Delete it. The heading carries its own weight. A hero pre-headline that calls out the reader in a full phrase is copy, and it stays |
| Gradient text, glass cards, glowing blobs | Weight and size for emphasis, flat colour, real depth only |
| Emoji as icons | One icon set with one stroke weight, or no icons |
| Everything centred | A real grid with a strong left edge |
| Three neat stats under the hero | Real numbers inside the sentence they prove. Unknown numbers stay [BRACKETS] |
| A system font for the headline | A display face with character from the type menu |
| Stock smiling people | The owner's real photos, or scenes with no fake customers |
| Fake dashboards and fake logos | The real product, or a labelled slot |
| Every section the same height and rhythm | Vary the composition. Give important sections more room |
| Low contrast grey text | Muted text still passes 4.5:1 at body size |

## Motion

Guardrails:

- Animate transform and opacity only (blur, clip-path and mask are fine when smooth). Never width, height, top, left or margins.
- Content is visible by default, so the page still reads if scripts fail.
- `prefers-reduced-motion` gets a still page. Hover colour and focus states still show.
- No fade-in on every card and section, no parallax on text, no scroll-jacking, no tilting cards, no carousels or auto-rotating tabs.
- Hovers 150 to 250ms. Entrances 600 to 1000ms with a strong ease-out.
- 3D and shader effects only for software, AI, gaming or a real product render, with a still fallback. A local business, coach or bakery gets great photos instead.

Menu:

| Type | Options |
|---|---|
| Hero entrance | Masked headline (each line rises from behind its baseline, the second line 110ms later), shutter image, word-by-word rise, scaling wordmark |
| Signature moment (pick one) | Pinned story, shutter image, scaling wordmark on scroll, edge marquee, index preview on hover, curtain footer, slow crossfade, drag row, colour on scroll, or stillness |
| Micro-interactions | Button lifts 1 to 2px on hover and presses on click, linked card lifts 2px, photo zooms 1.02 inside its frame, underline draws from the left, visible focus ring |
| Numbers | Count up only real numbers from the Brain, never a [BRACKET] |
