## Notes for Claude Code

- Installed agents live in `.claude/agents/`, created during setup. Delegate to them by name. If an agent isn't installed there, load its card from `agents/` instead.
- Commands: `/setup` runs the setup protocol, `/brief` gives the daily or weekly brief, `/add-agent` adds one agent.
- Ask before running any command that sends, publishes, spends, deletes or changes something live.
