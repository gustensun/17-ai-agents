# Taste

Agents learn a standard faster from examples than from rules. Each file here shows the same job done badly, done well and done very well, with notes on what makes the difference. Read the file that matches your deliverable before you start, and again before you hand it over.

| File | Shows | Used by |
|---|---|---|
| [copy-bad-vs-great.md](copy-bad-vs-great.md) | Headlines, heroes, buttons and sales copy | CMO, Copywriter, Funnel |
| [design-ai-vs-designed.md](design-ai-vs-designed.md) | Pages, graphics and app screens | Design, Funnel, Coding |
| [content-ideas.md](content-ideas.md) | Content ideas, outliers and research findings | Research, Creator, Content |
| [reports.md](reports.md) | Briefs, reports, lists and test results | COO, Research, Automations, CRM, QA, Lead Gen, Accounting, Analytics |
| [replies.md](replies.md) | Emails and DMs to customers and leads | Support, Sales |

## The four questions

Every "great" example in this folder passes the same four questions. Ask them about your own work before you hand it over.

1. Is it specific to this reader, this business and this moment?
2. Is every claim true, and backed by something the reader could check?
3. Is the next step obvious?
4. Does it sound like the owner talking, in plain words?

## How taste grows

1. These files set the starting standard. They're the same for every business.
2. The owner's ratings go into `my-business/taste-log.md`, each with a reason. Newer ratings win over these files (the order of authority is in [brain/CORE.md](../brain/CORE.md)).
3. Work the owner rates 4 or 5 is saved in `my-business/examples/<agent>/`. Those become the agent's best examples, in the owner's own voice.
4. When the owner gives the same reason twice, the agent turns it into a rule in its setup file.

The examples use made-up businesses, people and numbers. They show the shape of good work. They're never facts to reuse.
